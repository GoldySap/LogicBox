# Changelog

## 1.1.0

- Added rendering material, texture, mesh, light, and instance primitives.
- Added physics world, raycasting, joints, collision layers, and fixed-step integration.
- Added animation clips, state machines, navmesh, and pathfinding.
- Added TCP framing, reliable UDP packets, replication, and network sessions.
- Added asset manifests and hot reload watching.
- Added persistence migrations, SQLite helpers, spatial audio buses,
  inspector, crash reporting, rollback, and capability policies.

## 1.0.0

- Initial production-oriented release.
- Added nodes, components, signals, scene serialization, scheduling, input,
  fixed-update lifecycle, physics primitives, UI, audio, plugins, diagnostics,
  and configuration.
- Added terminal, Pygame, and ModernGL driver implementations.
